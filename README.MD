# Kansas Metal Fabrication Company Directory SQL Project

This project is a SQL database of Kansas metal fabrication companies. The database includes company name, location, company size, and specialization.

## Tools Used
- Supabase
- PostgreSQL
- SQL
- Excel
- GitHub

## Project Purpose
The goal of this project was to practice building a real SQL database using company directory data. I created a table in Supabase, imported company data, and wrote SQL queries to organize and analyze fabrication companies by location, company size, and specialization.

## Database Columns
- company_name
- location
- company_size
- specialization

## Example SQL Queries
This project includes queries that:
- List all companies alphabetically
- Find structural steel fabrication firms
- Count shops by company size
- Rank shop locations by count
- Rank specializations by frequency

## Project Summary
I built this project to practice SQL, data organization, and database analysis using a real-world industry related to metal fabrication and manufacturing.
